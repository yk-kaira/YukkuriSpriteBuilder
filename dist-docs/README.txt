--------------------------------------------------------------------------------
 1. このツールでできること
--------------------------------------------------------------------------------
Photoshop形式(PSD)の立ち絵を、レイヤー構造・名前・不透明度・合成モード・
表示/非表示を保ったまま、まとめて高画質化します。

  (1) PSDを分解する      ... レイヤーごとのPNGと、レイヤー情報(JSON)に分解
  (2) 高画質化する       ... waifu2x-caffe で各PNGを拡大・ノイズ除去
  (3) PSDを再構築する    ... 元と同じ構造の高画質PSD「○○_x2.psd」を出力
  (4) YMM4用の設定を作る ... 口パク・まばたきの設定ファイル「○○_x2-ymm.json」を出力

複数のPSDをまとめて指定して、同時に処理することもできます。
元のPSDファイルは書き換えません。


--------------------------------------------------------------------------------
 2. 必要なもの
--------------------------------------------------------------------------------
  - Windows (64bit)
  - Python 3 （3-1 を参照）
  - Pythonのライブラリ psd-tools と Pillow （3-2 を参照）
  - waifu2x-caffe の CLI版 waifu2x-caffe-cui.exe （3-3 を参照）
  - 立ち絵PSD（あなたが利用できる素材）

※ ysp.exe には Java の実行環境が含まれています。Javaを別にインストールする
  必要はありません。
※ 動作確認環境: Windows / Python 3.14 / waifu2x-caffe（cuDNN処理）


--------------------------------------------------------------------------------
 3. 初期設定（初回のみ）
--------------------------------------------------------------------------------
■ 3-1. Python 3 をインストールする
  1) 次のページから Python 3 のインストーラーをダウンロードして実行します。
       https://www.python.org/downloads/
  2) インストーラーの最初の画面で、必ず次のチェックを入れてから進めてください。
       [x] Add python.exe to PATH      （または「PATHに追加」）
     ※ 新しいPythonのインストーラー(Python install manager)を使う場合は、画面の
       案内に従ってインストールしてください。
  3) インストール後、「コマンドプロンプト」または「PowerShell」を開いて、
     次のどちらかを入力し、バージョンが表示されれば成功です。
       python --version
       py -3 --version
     ※ 「python」と入力するとMicrosoft Storeが開く場合は、アプリ実行エイリアス
       の影響です。その場合は py -3 を使ってください（yspは py -3 も自動で探します）。

■ 3-2. psd-tools と Pillow をインストールする
  コマンドプロンプト（またはPowerShell）で、次を1行ずつ実行します。
  （python が使えない場合は、先頭を py -3 に置き換えてください）

       python -m pip install --upgrade pip
       python -m pip install psd-tools Pillow

  確認コマンド（「OK」と表示されれば成功です）:

       python -c "import psd_tools, PIL; print('OK')"

  ※ psd-tools は PSD を読み込むため、Pillow は画像を扱うために使います。
  ※ 会社・学校のPCなどで権限エラーが出る場合は、末尾に --user を付けてください。
       python -m pip install --user psd-tools Pillow

■ 3-3. waifu2x-caffe を用意する
  1) waifu2x-caffe を入手して、好きな場所に展開します。
       https://github.com/lltcggie/waifu2x-caffe
  2) 展開したフォルダにある「waifu2x-caffe-cui.exe」（コンソール版）の場所を
     メモしておきます。（GUI版の waifu2x-caffe.exe だけでは動きません。
     同じフォルダに -cui.exe がある場合は、yspが自動で切り替えます）
  3) NVIDIA製GPUがある場合は、処理方式で「cudnn」を選ぶと高速です。
     使えない環境では「gpu」または「cpu」を選んでください。

■ 3-4. ysp を起動して「環境チェック」を行う
  1) ysp.exe をダブルクリックして起動します。
     （Windowsの「SmartScreen」で警告が出た場合は、「詳細情報」→「実行」を選びます。
       個人配布のため、発行元の署名がないことによる表示です）
  2) 「ツール」欄の「waifu2x-caffe-cui」に、3-3 の waifu2x-caffe-cui.exe を
     「参照...」から指定します。
  3) Pythonは通常は空欄（自動検出）のままで構いません。見つからない場合だけ
     python.exe のパスを指定してください。
  4) 下部の「環境チェック」ボタンを押します。ログに次のように表示されれば準備完了です。
       [OK] Python と psd-tools / Pillow を確認しました
       [OK] waifu2x: C:\...\waifu2x-caffe-cui.exe
     ※ waifu2xの場所は保存され、次回からは入力不要です。

 4. GUIの使い方
--------------------------------------------------------------------------------
■ 4-1. 基本の流れ
  1) 「処理するPSD」へ、PSDファイル（またはPSDが入ったフォルダ）をドラッグ&ドロップ
     します。「ファイル追加...」「フォルダ追加...」ボタンでも追加できます。
     複数まとめて追加できます。
  2) 必要なら「処理設定」を調整します（初期値のままでも使えます）。
  3) 「実行」ボタンを押します。ログ欄に進行状況が表示されます。
  4) 「完了」と表示されたら終了です。PSDと同じフォルダに結果が出力されます。
  ※ 途中でやめたいときは「中止」ボタンを押します。

■ 4-2. 各項目の説明
  [処理するPSD]
    フォルダを追加した場合は、そのフォルダ直下の *.psd をすべて処理します。
    （本ツールの出力である「○○_x2.psd」は、フォルダ指定では対象から除外します）

  [ツール]
    waifu2x-caffe-cui : waifu2x-caffe-cui.exe（またはそれがあるフォルダ）
    Python (空欄=自動) : 通常は空欄でOK。見つからないときだけ python.exe を指定

  [処理設定]
    拡大率                  : 既定 2（2倍）。1にするとノイズ除去のみになります
    ノイズ除去              : なし / 0〜3（数字が大きいほど強くかかります）
    処理方式                : 既定 / cpu / gpu / cudnn
    同時に処理するPSD数     : 既定 2。メモリが足りないときは 1 にしてください
    同時に動かすwaifu2x数   : 既定 1。GPUが1枚のときは 1 を推奨します
    実行するステップ        : 通常は3つともON。
                              「3 PSD再構築」だけにすると、すでに高画質化済みの画像から
                              PSDを作り直せます（画像やJSONを手で直したあとなどに便利）
    waifu2x追加引数         : waifu2xへ渡す追加オプション（上級者向け。通常は空欄）

  [YukkuriMovieMaker 立ち絵設定 (口パク / まばたき)]
    生成する                : ONで「○○_x2-ymm.json」を出力
    既存の設定を上書きする  : 既に同名ファイルがある場合、通常は上書きしません
                              （YMM4で調整した内容を守るため）。作り直したいときだけON
    n番号                   : 0 / 1 / none。YMM4で口パク・まばたきの対象がずれる場合に
                              1 または none を試してください
    判定ルール(任意)        : レイヤー名の判定キーワードを変えたいときに、JSONファイルで指定

  [ボタン]
    実行 / 中止 / 環境チェック / このアプリについて

  ※ 設定内容は、次回起動時に引き継がれます（PSDの一覧は引き継ぎません）。

■ 4-3. 出力されるファイル
  元のPSDが「D:\work\chara.psd」の場合（拡大率2のとき）:

    D:\work\
      chara.psd                ... 元のPSD（変更しません）
      chara_x2.psd             ... 高画質化したPSD（再構築結果）
      chara_x2-ymm.json        ... YMM4用の立ち絵設定（口パク・まばたき）
      chara_part\              ... 作業用フォルダ
        chara.json             ... レイヤー情報
        x1\                    ... 分解した画像（PSDのフォルダ階層と同じ構造）
        x2\                    ... 高画質化した画像（同上）

  ※ 作業用フォルダ内の x1 と x2 は、実行のたびに削除して作り直します。
    手で編集した画像を残したい場合は、別の場所にコピーしておいてください。
  ※ 不要になれば chara_part フォルダは削除して構いません。

■ 4-4. YMM4で使う
  1) 出力された「○○_x2.psd」と「○○_x2-ymm.json」を、同じフォルダに置いたまま
     使います（yspはすでに同じフォルダに出力しています）。
  2) YMM4で「○○_x2.psd」を立ち絵として読み込むと、口パク・まばたきの設定が
     自動で反映されます。
  3) 口パク・まばたきのレイヤーは、次のレイヤー名の規則で自動判定しています。
       口パク   : 名前が「口」のフォルダの中で、
                  「開け」「あわわ」を含む = 開いた口、「閉じ」を含む = 閉じた口、
                  「笑」を含む = 笑顔用（開いた口と閉じた口のペアを作ります）
       まばたき : 名前が「目」のフォルダの中で、
                  「普通目」「通常目」= 開いた目、「閉じ」= 閉じた目、
                  「半目」「半開」があれば 開→半→閉 の3枚構成
     （先頭の「!」「*」や、末尾の「 #1」などは無視して判定します）
  4) 命名が異なる立ち絵は、「判定ルール」にJSONを指定すると変更できます。
       { "mouth_groups": ["くち"], "eye_groups": ["め"],
         "mouth_closed": ["閉じ"], "smile": ["笑"], "mouth_open": ["開け"],
         "eye_open": ["普通目"], "eye_half": ["半目"], "eye_closed": ["閉じ"] }
  5) 自動生成の内容でうまく動かないときは、YMM4側の設定画面で口パク・まばたきを
     手動で設定してください。YMM4で調整した設定は、次回以降も上書きされません。

 5. 変換の仕様と注意点
--------------------------------------------------------------------------------
  - レイヤーマスクは、画像の透明度に統合して出力します。出力PSDにマスクは残りません。
    （フォルダに掛かっているマスクは、中のレイヤーそれぞれに統合します。通常合成
     以外の合成モードの場合、見た目が少し変わることがあります）
  - テキスト・シェイプ・スマートオブジェクトなどは、画像（ラスタ）として出力します。
  - 調整レイヤーなど、画像を持たないレイヤーは出力されません（ログに表示されます）。
  - クリッピング、レイヤー効果、ロック状態は再現されない場合があります。
  - 出力PSDのプレビュー用の合成画像は簡易的なものです。Photoshop等で開いて保存し直す
    と更新されます。レイヤーを読み込む用途（YMM4等）には影響しません。
  - 出力PSDは Photoshop形式（RGB / 8bit）です。高画質化後のサイズによっては、
    PSDの上限（1辺30000ピクセル）を超えるとエラーになります。
  - 大きなPSDや枚数が多い場合は、メモリを多く使います。「同時に処理するPSD数」を
    1にしてください。
  - 処理後の結果は、必ずご自身で目視確認してください。

 6. うまく動かないとき
--------------------------------------------------------------------------------
  Q. 「使用できるPythonが見つかりません」と表示される
  A. 3-1 でPythonをインストールしたか確認してください。「Add python.exe to PATH」を
     入れ忘れた場合は、Pythonをインストールし直すか、「Python (空欄=自動)」に
     python.exe のフルパスを指定してください。
     （場所を調べるコマンド:  py -3 -c "import sys; print(sys.executable)" ）

  Q. 「psd-tools / Pillow がありません」と表示される
  A. 3-2 のコマンドを、yspが使うPythonと同じPythonで実行してください。
     Pythonが複数入っている場合は、python.exe のフルパスを指定し、そのPythonで
       "C:\...\python.exe" -m pip install psd-tools Pillow
     を実行します。

  Q. waifu2xの実行でエラーになる
  A. 処理方式を cudnn → gpu → cpu の順に変えて試してください。
     waifu2x-caffe-cui.exe を単体で実行できるかも確認してください。
     ※ waifu2xのログが文字化けすることがありますが、処理自体には影響しません。

  Q. 「images missing」のようなエラーが出る
  A. 高画質化後の画像が出力されていません。waifu2xのエラーが出ていないか、
     chara_part\x2 フォルダに画像があるかを確認してください。

  Q. 口パク・まばたきがYMM4で正しく動かない
  A. 4-4 のレイヤー名の規則に合っているか確認してください。対象がずれる場合は、
     「n番号」を 1 または none に変えて、「既存の設定を上書きする」をONにして
     再実行します。

  Q. 起動時にWindowsが警告を出す / ウイルス対策ソフトが反応する
  A. 個人配布のため発行元の署名がありません。ご自身でダウンロード元を確認のうえ、
     問題なければ許可してください。

  Q. 処理中に止まったように見える
  A. 大きな画像のwaifu2x処理は時間がかかります。ログ欄が更新されていれば動作中です。

      AIアシスタント。本ツールの開発に利用しました。

      https://github.com/psd-tools/psd-tools
